# Design notes

Why each part exists, and the failure it prevents.

## Reading: load little, search well
- **Only `MEMORY.md` is always loaded.** Everything else is opened on demand. A brain that loads
  everything into every session fills the context with history and pushes out the question.
- **Two-line frontmatter** (`description`, `updated`) on every file. The description says what the
  file holds *and when to read it*. An agent greps descriptions, then opens only the matches.
- **`INDEX.md`** is the same list in one file, generated by `scripts/build-index.py`, for tools
  without a shell.
- **`Related:` lines** let an agent walk from file to file instead of searching again.
- **Inline and spill:** `scripts/log-recent.py` prints the newest log entries in full and only a
  count for the rest, so long append-only logs stay cheap.

## Writing: agents record, with limits
- `procedures/capture.md` gives agents a licence to write facts, decisions and lessons as they go.
  They ask first only when a fact would overwrite something, belongs to someone else, is sensitive,
  or is their own inference.
- **Correction routing** sends each correction to the place where it changes future work: a fact
  to a note, a choice to `decisions.md`, a repeated preference to a Standing rule, a technique to a
  procedure, a dangerous action to a mechanical gate.
- **Session digests** in `sessions/` are short-term memory. They are not a source of truth until
  the dream has compiled them.

## Consolidating: the weekly dream
- Four steps: enrich (fold digests in), verify (deadlines, expiries, staleness, broken sources),
  organise (frontmatter, names, links, index), report (one screen).
- **Safe fixes are applied; fact changes are proposed.** The owner stays the judge of truth.
- **Before-copies** in `archive/dream-snapshots/<date>/` give a rollback in synced folders where git
  is awkward.
- The **watchdog** checks the brain's own health first.

## Safety
- **Standing rules** are numbered, short and kept apart from the folder map, so a long session
  cannot paraphrase them away.
- **Never delete.** Move to `archive/`. Never invent. Record both sides of a disagreement.
- **`_sensitive-hold/`** quarantines anything holding credentials. Agents may move files in, never out.
- **Reference numbers** live in their own note, not in the always-loaded file.

## Masters and copies
`CLAUDE.md` and `notes/writing-standard.md` are the masters. `PROJECT-INSTRUCTIONS.md` and anything
pasted into other tools are copies. Change the master first; the dream reports drift between them.

## What it deliberately does not do
- No database, no vector store, no plugin. Grep and Markdown are enough at personal scale.
- No wiki-link syntax, so the files read the same in any editor.
- No nagging. The dream reports open items; it does not chase.
