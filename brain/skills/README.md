# Skills: master copies

One folder per skill you write: `skills/<name>/SKILL.md`, plus any templates or worked examples it
needs beside it. Any approved tool can use a skill: open the `SKILL.md` and follow it.

## Rules
- The copy here is the master. Tools that keep their own skills (Claude skills, custom GPTs, Gems)
  get a pasted copy. Change the master first, then paste it again.
- Keep reference facts in `notes/`, not in a skill. A skill says how to do a job; the brain says
  what is true.
- Generic skills that ship with a tool (document formats and the like) do not belong here.

## SKILL.md skeleton
```
---
name: <skill-name>
description: "One line: what the skill does and when to use it."
---
# <Skill name>

## Inputs
## Steps
## Output
## Checks before you finish
```
