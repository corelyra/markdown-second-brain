# MEMORY: long-term core facts

One-line facts that should always be in the agent's head. Keep this short and curated: about
70 lines. Anything longer belongs in a note, with a pointer here. Numbers of seven digits or more
(account, policy, passport numbers) go in `notes/reference-numbers.md`, never here; the watchdog
checks for them.

## Who I am
- Name, preferred name, timezone, languages.

## Family and household
- Who lives with you, and which of their records the brain may hold (see Standing rule 7).

## Home
- Where you live, tenure (own / rent), the one or two facts an agent needs (landlord file, renewal month).

## Work
- Current role or engagement, and the file that holds the detail.

## Money
- Pointers only: which note holds banks, pensions, investments, tax. No balances here.

## Health
- Only what an agent must know to give safe advice (allergies, a condition that changes suggestions).

## Standing context (kept current, last touched DD Mon YYYY)
- What is live this month: the main project, the current search or move, the next big date.

## How I work
- Tools, routines and preferences an agent should respect.
