# MEMORY: long-term core facts

The hub of a star schema: one short line per topic, each ending in a link to the note, person or
project file that holds the detail. Add detail to that file, never here. About 60 lines at most. Numbers of seven digits or more
(account, policy, passport numbers) go in `notes/reference-numbers.md`, never here; the watchdog
checks for them.

## Who I am
- Name, preferred name, timezone, languages. See `notes/<identity-note>.md`.

## Family and household
- Who lives with you, and which of their records the brain may hold (see Standing rule 7). See `people/<name>.md`.

## Home
- Where you live, tenure (own / rent), the one fact an agent needs. See `notes/<tenancy-or-home>.md`.

## Work
- Current role or engagement. See `people/<employer>.md`.

## Money
- Pointers only: banks, pensions, investments, tax, each with its note. No balances here.

## Health
- Only what an agent must know to give safe advice (allergies, a condition that changes suggestions), with its note.

## Standing context (kept current, last touched DD Mon YYYY)
- What is live this month: the main project, the current search or move, the next big date, each with its project file.

## How I work
- Tools, routines and preferences an agent should respect. See `notes/writing-standard.md`, `notes/scheduled-jobs.md`.
